## Wanted

Tripwire has one maintainer, and wants more, especially from organizations
not already represented. Areas where help would make the biggest difference:

- vector store connectors (Weaviate, Pinecone, Elasticsearch),
- the OpenTelemetry processor,
- SIEM output formats,
- realistic canary generation.

If you're interested, start with an issue labelled `good first issue` or
`help wanted`, or open an issue to say what you'd like to work on.
