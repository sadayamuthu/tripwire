# Code of Conduct

Tripwire adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone taking part in the project:
in issues, pull requests, discussions, and any other project space, and when
someone represents the project elsewhere.

In short: be respectful and constructive, assume good faith, and don't
harass, demean or exclude anyone.

## Reporting

To report behaviour that breaks the code of conduct, email
**[sadayamuthu@outlook.com](mailto:sadayamuthu@outlook.com)**. Reports are read only by the
maintainers listed in [MAINTAINERS.md](MAINTAINERS.md); if a report concerns
one of them, that maintainer is left out of handling it.

Maintainers will review every report, respond, and act as the Contributor
Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
describe, from a private warning up to a permanent ban. Reporters' identities
are kept confidential.
